# 🤖 Library & Book Recommendation AI Agents

This project is a multi-agent AI system built using Google ADK and Gemini models.

## 📌 Project Overview

It contains two intelligent agents:

### 📚 Library Main Agent
- Finds libraries near user location
- Calculates distance based on city rules
- Checks opening hours and availability
- Filters results within requested radius

### 📖 Book Main Agent
- Recommends books by category
- Provides book reviews and summaries
- Finds book availability in libraries
- Classifies books by difficulty level

---

## 🧠 Technology Used

- Google ADK (Agent Development Kit)
- Gemini 2.5 Flash Model
- Google Search Tool
- Python

---

## 🌍 Supported Features

- Myanmar cities support (Mandalay, Yangon, etc.)
- Smart distance estimation

- Book recommendation engine

## 🚀 Purpose

To build a real-world AI assistant system combining location intelligence + knowledge recommendation.
